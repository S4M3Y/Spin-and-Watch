# Spin & Watch

A responsive, no-backend movie and series decision wheel built with plain HTML, CSS, and vanilla JavaScript.

## Run locally

1. Download and extract the project ZIP.
2. Open `index.html` in a modern browser.

For a local development server, run this command from the project folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Features

- Independent genre and Movie/Series wheels
- Smooth deceleration, randomized results, and Spin Both
- IMDb title search links that update when both choices are ready
- Reset, keyboard-accessible buttons, and reduced-motion support
- Responsive layout for mobile, tablet, and desktop
- No backend, account, API key, or build step required
